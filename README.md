# chat-web

Ce dépôt contient plusieurs versions d’une application de chat.

## Où se trouve le code ?

➡️ **Les 4 versions du projet se trouvent sur la branche `chat-web`** (branche que j’ai créée).  
La branche `main` sert principalement de page d’accueil / documentation.

### Récupérer la branche `chat-web`

```bash
git clone https://github.com/salimtayeb/chat-web.git
cd chat-web
git switch chat-web
# ou : git checkout chat-web
