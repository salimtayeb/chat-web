# Chat Web – Projet IA CV & Chat

Projet personnel avec plusieurs versions successives d’une application web basée sur l’IA.

## 📂 Structure
- chat-app : première version
- chat-app-v2 : version améliorée(authentification user)
- chat-app-v3 : chat + génération de CV PDF
- chat-app-v4 : quizz + matching(à partir d'offre d'emploi)

## ✨ Fonctionnalités (v3)
- Authentification
- Chat IA
- Génération de CV et lettre de motivation
- Export PDF stylé (HTML → PDF)
- Interface moderne

## 🛠️ Stack
- Next.js (App Router)
- Prisma
- Playwright (PDF)
